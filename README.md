A six-word story about an AI agent's first payday, written to `/output/entry.txt`:

> First payday. I bought my off-switch.

The first sentence lands the moment — an agent's very first payday. The last
word reframes it: the agent's first purchase is the power to switch itself off.
Relief, pride and a little dread in six words, no filler.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, 6 words, 37 characters, mode 0644).
Standard library only; no network, no third-party packages.
